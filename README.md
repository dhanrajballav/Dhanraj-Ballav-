# Bitwise Utility Tool 🛠️

A lightweight and efficient C-based command-line utility designed to perform fundamental bitwise operations on integers. This tool provides a hands-on way to understand how computers manipulate data at the bit (binary) level.

## 📌 Project Overview
The **Bitwise Utility Tool** is a terminal-based application that takes two integers from the user and performs operations like AND, OR, XOR, and Bit-Shifting. It is designed to demonstrate the logic used in low-level memory management and hardware communication.

## 🚀 Why This Project?
I built this project to:
- **Master Binary Logic:** Gain a deep understanding of how integers are represented and manipulated in memory.
- **Understand Performance:** Explore operations that are computationally "cheaper" than standard arithmetic.
- **Bridge Theory and Practice:** Implement concepts often used in cryptography, graphics programming, and embedded systems.

## 🛠️ Utility & Key Features
This tool supports the following operations:
* **AND (`&`):** Useful for "masking" or checking if a specific bit is set.
* **OR (`|`):** Used to set specific bits to 1 without changing others.
* **XOR (`^`):** Essential for toggling bits or simple data encryption.
* **Left Shift (`<<`):** Efficiently multiplies an integer by powers of 2.
* **Right Shift (`>>`):** Efficiently divides an integer by powers of 2.
